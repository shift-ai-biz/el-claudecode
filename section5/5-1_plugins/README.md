# 5-1 プラグイン導入ワーク

導入するのは、3-5 で名前だけ紹介した `skill-creator`（Anthropic公式マーケットプレイス）です。
Skill そのものを設計・改善するためのプラグインで、**提供しているのは Skill で、
コマンドやサブエージェントは含みません**。そのため、増えたものの確認には `/skills` を使います。

```text
/plugin        # プラグイン管理画面を開き、マーケットプレイスから skill-creator をインストールする
/skills        # skill-creator のSkillが一覧に増えていることを確認する
```

インストールが終わったら、チーム展開を想定して導入手順を `CLAUDE.md` に書き残してください。
ほかのメンバーが同じ手順で再現できる粒度で書けているかが評価観点です。

> マーケットプレイスの内容は変わることがあります。`skill-creator` が見当たらない場合は
> ほかのプラグインで進めても構いません（その場合、そのプラグインが何を追加したかに応じて
> 確認するコマンドを選んでください）。
