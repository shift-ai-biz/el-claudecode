# 3-4 checkpoint と /rewind ワーク

`report.py` を題材に、**わざと大きすぎる変更を出させてから巻き戻す**ワークです。

1. 「派手なリファクタリングをして」と依頼する
2. 変更内容を確認する（方向性が違った、という前提で進めます）
3. `/rewind`（または Esc を2回）で、依頼する前の時点に戻す
4. `report.py` が依頼前と完全に一致していることを確認する
5. 「関数分割はしていいが、命名は変えないで」と指示を変えて再挑戦する

`python report.py` を実行すると、巻き戻し前後で同じ出力になることを確認できます。
