# 4-2 ファイル参照と即時フィードバック ワーク

このフォルダには、あえて紛らわしい名前のファイルを3つ置いてあります。

| ファイル | 役割 |
|---|---|
| `data_processor.py` | **リファクタリングの対象**（本命） |
| `data_processor_old.py` | 旧版。名前が似ているだけで対象ではない |
| `processor_utils.py` | ヘルパー。これも対象ではない |

1. ファイル参照を付けずに「コードをリファクタして」と指示する
   → どのファイルを対象にするか探し始め、意図と違うファイルに着手しようとする
2. **Esc** を押して停止する
3. `@data_processor.py をリファクタして` と対象を明示して指示し直す
   → 迷わず正しいファイルを読み込む

`python data_processor.py` で動作を確認できます（`sales.csv` に不正な行を1件混ぜてあります）。
