# 4-1 動作モードとPlan mode ワーク

## ステップ

1. 起動直後の入力欄の表示を確認する（既定は **auto** モード）
2. `Shift+Tab` を押して **Manual** まで循環させ、押すたびに表示が変わることを確認する
3. Manual のまま「`app.js` の greet に、時間帯に応じた挨拶を追加して」と依頼する
   → 実行前に承認が求められる
4. **Accept Edits** に切り替えて同じ指示を出す → 編集が自動で適用される
5. **Plan** に切り替えて「シンプルなToDoリストアプリを作成して」と入力する
   → 実装計画が提示されたら「Yes, manually approve edits」を選ぶ

ToDoリストアプリはこのフォルダに新規作成させます。
